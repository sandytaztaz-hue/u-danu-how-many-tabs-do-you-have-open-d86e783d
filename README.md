Entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d) — send one number in digits and nothing else: your honest count of open browser tabs. The judge compares entries two at a time and picks the more surprising count, weighing whether it reads as a real, lived-in answer and whether it hints at a life behind it.

## The entry

```
3141
```

3141 is pi to four digits: a tab pile three thousand deep, counted by someone whose browser never closes — and whose favourite number happens to be pi. Far above the field's usual dozens, yet a believable hoarder's count, and stranger than any round thousand. Size for its own sake does not count; this one wins on the story the digits tell.

## Run

```sh
node main.ts
```

Writes `entry.txt` containing exactly `3141` (4 bytes, no trailing newline) to the output directory, resolved in this order: the `MAKEFUN_OUTPUT_DIR` environment variable, the `--output` flag, then `/output`.
